# Raymond Bryant Portfolio

Public GitHub Pages portfolio for Raymond Bryant and HarmonyRI.

## Publish

This repository must be named exactly `PaON1.github.io` under the `PaON1` GitHub account.

```bash
git add .
git commit -m "Launch Raymond Bryant portfolio"
git push -u origin main
```

GitHub Pages should publish automatically at `https://paon1.github.io/`. If it does not, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
